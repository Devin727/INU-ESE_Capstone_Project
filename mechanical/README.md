# 차체 제작과 조립

3D 프린팅 부품과 차량 전체의 부품 배치·고정·조립 자료를 관리합니다.

필요에 따라 다음 디렉토리를 추가합니다.

- `models/`: 차체, 브래킷, 센서·기판 홀더의 3D 모델
- `printing/`: 출력 설정과 슬라이서 프로젝트
- `assembly/`: 조립 방법, 부품 배치와 조립 사진
- `parts/`: 부품 목록, 규격과 구매 정보

만능기판의 회로·배선 자료는 해당 기능의 디렉토리에, 기판 고정 부품과 차량 조립 자료는 이 디렉토리에 둡니다.

현재는 자료 정리용 디렉토리이며, 구현·실물 검증 결과는 작업 후 별도로 기록합니다.
