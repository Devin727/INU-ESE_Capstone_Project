## 현재 연결부의 자원 요구량

| 장치 | 모터 1개 | 모터 6개일 때 |
|---|---|---|
| DRV8833 브리지 | 1개 | 6개, 독립 구동용 듀얼 모듈 3개 |
| 제어 출력 GPIO | 2개 | 12개 |
| LEDC 채널 | 2개 | 12개 |
| A/B 입력 GPIO | 2개 | 12개 |
| PCNT 유닛/채널 | 1/2개 | 6/12개 |

여기에 서보 7개, IMU·ToF, 초음파 회로, 상위 통신과 nSLEEP/nFAULT를 더해야 한다.
서보도 각각 LEDC를 사용한다면 필요한 LEDC 채널은 총 19개다. 선택한 칩의 실제 자원과 비교하고 다른 PWM 장치 또는 제어 분리가 필요한지 결정한다.
I2C 신호 공유, 외부 PWM 장치, 외부 활성화 회로에 따라 GPIO 요구량은 달라진다.
실제 보드가 없으므로 현재 핀 할당표와 단일 보드 수용 여부는 확정하지 않았다.

## 실물 시험 순서

1. 전원 분리 상태에서 핀·극성·공통 GND·신호 전압을 확인한다.
2. 모터 연결 전 부팅·리셋 시 구동 출력이 꺼져 있는지 확인한다.
3. 모터 하나를 낮은 출력으로 구동해 양방향과 코스트·브레이크를 확인한다.
4. 출력축을 여러 바퀴 수동 회전해 방향 부호와 실제 x4 카운트를 기록한다.
5. 외부 기준과 RPM을 비교하고 고속에서 누락·잡음과 장시간 카운터 동작을 확인한다.
6. 잘못된 명령·연결 끊김·리셋 후 자동 재개 여부를 확인한다.
7. PI 게인을 낮게 시작해 부하별 응답과 전류·발열·전원 강하를 측정한다.
8. 여러 모터 동시 구동과 상위 장치 연동을 시험한다.

PC 시험 결과를 위 실물 시험의 완료로 기록하지 않는다. 소프트웨어로 과전류를 직접 측정하는 기능은 없다.
