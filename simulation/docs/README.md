## 현재 상태 (2026-10-15)

- 배관 코스 9종: 직관, 수평 45°·90°, 위·아래 45°·90°, 데모(45° 후 90°), 3D 데모(위 45° → 수평 → 왼쪽 90°)
- 엘보 프리셋 5종: DV 90°(R61), DV 45°, DV 대곡 90°(R125), TS 90°, TS 45°
- 차체 모델 8종: three_wheel, three_segment, two_module, two_active, two_real, two_real_x, pirate_v, tracked
- 도구: 일괄 주행 벤치(`bench`), 부품 배치 검사(`layout_check`)
- 완료: pirate_v 토션 스프링 재측정 (`bench/pv2_*`) — 효과 없음

> **주의:** 2026-10-15 이전에 나온 벤치 결과는 전부 **재측정 대상**입니다. 벤치가 실행이 끝난 시뮬을 완전히 끄지 못해, 이전 실행의 시뮬이 같은 토픽에 옛 자세를 보내 결과가 섞였을 수 있습니다. 자세한 내용은 [06 알려진 문제](06_알려진_문제.md)와 [05 결과 요약](05_결과_요약.md)을 보세요.
