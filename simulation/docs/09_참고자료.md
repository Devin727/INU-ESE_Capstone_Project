## 4. 알고리즘과 시뮬 도구

- ROS 2 Humble, Gazebo Fortress (ign 6.18), ros_gz 0.244 — 이 PC에 설치된 버전.
- Gazebo 궤도 플러그인 (TrackController, TrackedVehicle): 배관 안에서는 동작하지 않음 (06 문서 10번).
- Gazebo 암묵적 스프링 댐퍼 설정 (`implicit_spring_damper`): Gazebo 예제 `tracked_vehicle_simple.sdf` 참고.
