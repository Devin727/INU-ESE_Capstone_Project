**아직 결과 없음.** 2026-10-19에 모델과 이전 벤치 결과를 모두 지우고 처음부터 다시 시작했습니다.

새 결과는 아래 형식으로 쌓습니다.

## 결과 파일 규칙

- 위치: `simulation/bench/`
- 이름에 날짜와 바꾼 설정을 넣습니다. 예: `<모델>_20261020_k1.5.csv`
- 로그 폴더 `<이름>_logs/`도 같이 둡니다 (실패 원인 확인용).
- 중요한 판단은 같은 조건 3회 이상 반복합니다 ([04](04_벤치마크_기준.md) 4절).
