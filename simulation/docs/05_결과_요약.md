## 2026-10-22 AIRo-7.1 재현 (`airo71`) 과 `snake_v` 여유 확인

`airo71` (옴니휠 = 방향별 마찰, 끝 반구 = 굴림축에 바로, ODE + 메시 배관)
- 직관: 5 cm/s 로 끝 마개까지. 전에 멈추던 원인은 끝 바퀴 굴림 관절이 돌아 바퀴 축이 누운 것 (썰매)
- 엘보: R61 90° 네 방향, 45° (R72), 대곡 90° (R125) 모두 통과 못 함. 지그재그 누름이 엘보 입구에서 쐐기가 됨.
  대곡 아래 엘보만 끝 링크 충돌 반경 10 mm 로 머리가 수직으로 꺾였으나, 매달린 머리 무게로 지그재그가 펴져 바퀴가 뜸
- 끝 반구 굴림으로는 몸이 20~30° 이상 잘 안 돎 (누름 약 5 N) -> 머리를 엘보 안쪽 벽으로 돌리지 못함
- 논문 (arXiv 2411.03660) 의 90° 통과는 R/D 약 1.3. R61 (R/D 0.61) 은 검증 사례 없음 -> 우리 배관에는 부적합으로 결론

`snake_v` 여유 (왼쪽 90° 기준, 한 가지씩 바꿈)

| 바꾼 것 | 왼쪽 90° |
|---|---|
| 모터 0.8배 / 0.6배 | 통과 / 통과 |
| 바퀴 마찰 0.8배 / 0.63배 | 통과 / 통과 |
| 무게 1.2배 / 1.5배 | 통과 / 실패 (축 회전 덜 됨) |
| 서보 토크 0.8배 / 0.6배 | 실패 (축 회전 덜 됨) / 실패 |
| 모터 0.6배 + 마찰 0.8배 + 무게 1.2배 | 통과 |
| 서보 위치 게인 2 -> 4 | 실패 (축 회전 풀림) |

- 약점은 엘보 앞 축 회전 (V 가 버티며 J3 로 몸을 돌림). 회전 뒤 자세를 다시 재서 덜 돌았으면 다시 돌리게 함 (`rot_retries`, 최대 3번)
  -> 서보 0.8배도 통과. 무게 1.5배·서보 0.6배는 여전히 실패
- 위 90°: 기본 사양은 앞부분을 들어 올리는 F_PASS 에서 견인력 부족으로 정체 (전에 통과한 것과 실행마다 다름). 모터 1.5배면 엘보는 통과하나
  수직관 0.41 m 에서 멈춤. 모터·서보 함께 1.5배는 다시 엘보에서 정체
- 아래 90° (처음 시험): 몸 전체 180° 회전이 필요. J3 0.5 N·m 로는 약 60° 에서 멈춤 -> J3 2~3배 + 회전 대기 25 s 로 회전은 됨.
  그 뒤 앞부분이 처져 머리가 안쪽 모서리에 걸림 (서보 게인 4 면 수직관으로 내려가나 그 게인은 왼쪽·위를 망가뜨림)
- 결론: 왼쪽·오른쪽은 여유가 꽤 있음 (회전 반복 넣은 뒤). 위·아래는 기본 사양으로 불안정 -> 사양 하나로 네 방향을 다 통과하는 조합은 아직 없음
