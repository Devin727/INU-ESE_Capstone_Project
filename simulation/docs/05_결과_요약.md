| 위 90°, 몸통 1.1배 (0.132 kg) | +30° | 3/3 | 13~15 s |

- 굴림 방향은 엘보마다 맞춰야 함: +30° 는 왼쪽·위·아래, -30° 는 오른쪽·위·아래 통과, 반대쪽은 실패 (몸통 0.15 kg 시험, 3회 대칭이라 120° 마다 같음).
  wp6 에는 굴림 장치가 없어서 실물은 엘보 방향에 따라 몸을 돌리는 방법(관절 비틀기 서보 등)이 필요
- 위 엘보 (몸통 0.12 kg) 다른 실행 방식: 혼자 실행 4/4 (그중 2회는 CPU 10코어에 부하를 건 상태), RViz 화면 + 녹화 시연 1/2 (실패 1회는 엘보 입구 x 1.05 m 정체).
  실패를 다시 만들지 못해 원인 미확인 -> 위 엘보는 대부분 통과하지만 가끔 입구에서 멈출 수 있음
- 몸통(배터리·보드·카메라 포함, 모듈당) 0.12 kg 은 목표값. 0.15 kg 은 위 엘보가 불안정, 0.25 kg 은 실패
- 관절 서보를 세게(1.0 N·m) 하거나 약하게(게인 1.5) 해도, 예압을 올려도 나빠짐 -> 현재 0.52 N·m, 게인 3, 예압 8 N 유지
- 조건: oracle 제어 (배관 모양·정답 자세 사용, 시작 굴림은 손으로 줌), 시뮬 서보 = 위치 P 3 N·m/rad + 토크 한계
