# 10. wp6 3D 설계 자료

`wp6` (벽 밀착 6륜 2모듈, 지도교수 개념도) 를 3D 로 설계할 때 필요한 치수·조건을 한곳에 모은 문서입니다. 부품 선정은 빼고 기구만 다룹니다.

- 작성 2026-11-12. 원본은 [wp6.urdf.xacro](../src/pipe_robot_sim/models/wp6/wp6.urdf.xacro), [robot.yaml](../src/pipe_robot_sim/models/wp6/robot.yaml), [03](03_배관_규격.md), [05](05_결과_요약.md), [08](08_추정값_목록.md).
- **아래 값은 모두 시뮬 모델의 추정값**입니다 (배관 규격 제외). 확정 설계가 아니며, 실물 부품·실측으로 바꿔야 합니다.
- 시뮬 결과는 oracle 제어 (배관 모양·정답 자세 사용, 시작 굴림은 손으로 줌) 조건입니다.
- 개념도 그림, 치수도 (측면·정면 단면·엘보) 를 넣은 PDF 판: [10_wp6_3D설계_자료.pdf](10_wp6_3D설계_자료.pdf).

## 2. 전체 배치

좌표: 앞 모듈 몸통 중심 = 0, 앞 = +x, 위 = +z. 단위 mm.

```
 x:  +45        +25         0        -45 -55 -65       -110       -135      -155
     |앞 끝     |앞 바퀴 줄  |앞 중심   |   관절   |     뒤 중심   |뒤 바퀴 줄 |뒤 끝
     [====== 앞 모듈 90 ======]  10 ● 10  [====== 뒤 모듈 90 ======]
```

| 항목 | 값 |
|---|---|
| 몸통 전체 길이 | 200 mm (x +45 ~ −155) |
| 두 몸통 중심 사이 | 110 mm |
| 가운데 관절 중심 | x −55 mm (몸통 끝에서 10 mm) |
| 바퀴 줄 위치 | 앞 x +25, 뒤 x −135 (각 몸통 끝에서 20 mm 안쪽) |
| 바퀴 줄 사이 | 160 mm (관절에서 앞뒤 각 80 mm, 대칭) |
| 카메라 | 앞면 중앙 (시뮬 모형 Ø16 × 4 mm) |

## 3. 몸통 (모듈 2개, 같은 모양)

| 항목 | 값 | 비고 |
|---|---|---|
| 지름 × 길이 | Ø44 × 90 mm | 안에 배터리·보드·카메라 (시뮬은 질량만 반영) |
| 양 끝 | R22 반구로 둥글게 | 모서리가 엘보 안쪽에 걸리지 않게 |
| 질량 목표 (모듈당) | 0.12 kg | 배터리·보드·카메라 포함, 다리·바퀴 제외 |

## 4. 가운데 관절 (유니버설)

| 항목 | 값 | 비고 |
|---|---|---|
| 구조 | 앞 모듈 → 피치 (좌우 수평축) → 요 (수직축) → 뒤 모듈 | 두 축이 한 점에서 만남 |
| 범위 | 각 축 ±80° (±1.4 rad) | |
| 구동 | 서보 2개, 각도 명령 (`wp_ctrl`) | |
| 필요 토크 | 약 0.5 N·m 이상 | 시뮬: 0.35 N·m 이하는 위 엘보 실패, 0.52 N·m 통과 |
| 십자 질량 | 15 g | 추정 |

- 수동 토션 스프링 관절은 R61 엘보 입구에서 앞 바퀴 줄이 바깥 벽에 막혀 실패 ([05](05_결과_요약.md)).

## 5. 다리와 바퀴 (모듈마다 3개)

| 항목 | 값 | 비고 |
|---|---|---|
| 배치 | 축 둘레 120° 간격, 0번 다리 = 위 | |
| 바퀴 | Ø30 × 폭 10 mm, 고무 (마찰 0.8 가정) | 6개 모두 구동 |
| 바퀴 중심 반경 (직관) | 35.4 mm (= 50.4 − 15) | |
| 다리 움직임 | 반경 방향, 안쪽 15 mm / 바깥 15 mm | 바퀴 중심 반경 20.4 ~ 50.4 mm |
| 다리 구조 | 시뮬은 반경 방향 직선 슬라이더 | 실물은 평행 링크로 바퀴를 거의 반경 방향으로 움직이는 구조 가정 |
| 스프링 | 1000 N/m | |
| 예압 | 직관에서 바퀴 누름력 8 N (8 mm 압축) | 안쪽 15 mm 일 때 23 N |
| 질량 | 다리 + 모터 20 g, 바퀴 12 g (각) | 추정 |

- 끌림 팔 + 토션 스프링 다리는 시뮬에서 모터를 끈 채 로봇이 혼자 뒤로 가는 수치 현상이 있어 슬라이더로 바꿨습니다. 실물에 끌림 팔이 안 된다는 뜻은 아닙니다.

## 7. 시뮬에 없어서 3D 에서 정해야 할 것

시뮬은 로봇 부품끼리의 충돌 (self-collision) 을 계산하지 않습니다 (Gazebo 기본값). 다리·바퀴가 몸통을 파고들거나 두 모듈이 닿아도 시뮬은 통과로 나오므로, 아래 간섭은 3D 에서 직접 확인해야 합니다.

| 항목 | 내용 |
|---|---|
| 바퀴 ↔ 몸통 간섭 | 직관에서도 바퀴 안쪽 끝 (반경 20.4) 이 몸통 표면 (반경 22) 안으로 1.6 mm 들어감. 다리가 안쪽 15 mm 들어가면 바퀴 안쪽 끝 반경 5.4 mm → 몸통 홈, 안쪽 스트로크 축소, 몸통 지름 축소 중 하나 필요 |
| 모듈끼리 간섭 | 몸통 반구 끝끼리는 관절 굽힘 약 93° 에서 닿음 (계산값, 범위 ±80° 안에서는 안 닿음). 서보·다리를 포함한 간섭은 3D 에서 확인 |
| 모터 간섭 | 시뮬은 모터 크기 미반영. N20 (12 × 10 mm) 을 바퀴 축과 같은 방향으로 바퀴 옆에 두면 모터 길이 24 mm 기준 바깥 모서리가 반경 약 50.5 mm 로 배관 벽 (50.4 mm) 을 넘음 (계산값). 엘보 안은 더 좁음 → 모터 배치·기어 방향 확인 필요 |
| 테더 · 조명 | 개념도의 회수용 테더 고정부 (뒤 모듈 끝) 와 카메라 둘레 조명. 시뮬에는 없음 |
| 굴림 맞춤 장치 | 바퀴 줄을 엘보 방향에 맞춰 축 둘레 ±30° 돌려야 통과 (+30°: 왼쪽·위·아래, −30°: 오른쪽·위·아래). 시뮬은 시작 때 손으로 돌림, 실물 장치 없음 |
| 서보 크기·고정 | MG996R 40.6 × 19.8 × 42.9 mm 는 Ø44 몸통에 2개 넣기 어려움 |
| 다리 링크 실제 구조 | 평행 링크 / 끌림 팔 등, 스트로크 15 mm 와 예압 8 N 을 맞추는 구조 |
| 배선 경로 | 앞뒤 모듈 사이 배선이 관절 (±80°) 을 지나는 방법 |
| UT 탐촉자 위치 | 미정 (탐촉자 외경·높이 미확인, [08](08_추정값_목록.md)) |
| 엘보 실측 | R, 몸통 내경은 추정 상한값. 실물 측정 후 설계 여유 재확인 |

## 8. 3D 설계 후 할 일

1. 실제 질량·치수를 [wp6.urdf.xacro](../src/pipe_robot_sim/models/wp6/wp6.urdf.xacro) 에 반영 (`Lb`, `rb`, `gap`, `rw`, `ring_in`, `m_*`).
2. 바퀴 줄 위치를 바꾸면 [robot.yaml](../src/pipe_robot_sim/models/wp6/robot.yaml) 의 `ring_front_x`, `ring_rear_x` 도 같이 수정.
3. `bench` 로 좌·우·위·아래 90° 를 다시 시험하고 [05](05_결과_요약.md) 에 기록.
