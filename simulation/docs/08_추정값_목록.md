## 추정값을 바꾸면 할 일

1. 해당 값을 `robot.yaml` 또는 `layout.yaml`에서 수정 (재빌드 불필요).
2. `layout_check`를 다시 돌려 질량·무게중심 반영 (`--apply`).
3. `two_real` 등 해당 모델을 13개 배관 전체 재측정하고, 3회 반복 측정이 필요한 항목은 반복.
4. 결과 파일 이름에 날짜와 설정 값을 넣어 보관 (예: `two_real_20261020_k1.5.csv`).
