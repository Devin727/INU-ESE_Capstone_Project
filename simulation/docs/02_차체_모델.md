# 02. 차체 모델

2026-10-19에 차체 설계를 처음부터 다시 하기로 하고 이전 모델을 모두 지웠습니다 (이전 기록은 git 커밋 `810a8d1`). 지금은 **논문 로봇을 재현한 참고 모델 2종**만 있고, 아직 시뮬에서 시험하지 않았습니다.

## 0. 현재 모델

| 모델 | 원본 | 구조 | 상태 |
|---|---|---|---|
| `snake_v` | PIRATE (Dertien 2014) 방식 뱀형 V자 | 링크 6개, 관절 6개 (피치 5 + 가운데 비틀기 J3), 관절마다 바퀴 한 쌍(12개 구동). 앞뒤 V로 벽을 눌러 버팀. 0.64 kg | 수평 좌·우 90°, 위 90° 엘보 통과 (oracle 제어, [05](05_결과_요약.md)) |
| `snake_v2` | `snake_v` + 실제 부품 + 꼬리 끝 탐촉자 (D안) | 부품 상자(서보, N20 6개, 18650, ESP32, Pi, 카메라), 머리 ToF 3개, 뒤 V 꼬리 끝 탐촉자(들어올림 + 자가 정렬 슈). 0.59 kg (추정) | 탐촉자 없으면 엘보 통과, 달면 엘보 입구에서 멈춤 (여유 부족, [05](05_결과_요약.md)) |

- 논문에 없는 치수는 그림 비율로 추정했고, xacro 주석에 `추정`으로 표시했습니다. 목록은 [08](08_추정값_목록.md) 2절.
- 공통 부품(옴니휠 롤러, 관성, 시뮬 플러그인)은 `models/common/common.xacro`의 매크로입니다. 옴니휠은 허브 + 롤러 2줄 × 5개이며, 롤러마다 자유 회전 관절과 구 충돌체가 있습니다.

## 0-1. 모델 보기 (VS Code)

- 확장 **URDF Visualizer** (`morningfrog.urdf-visualizer`)로 xacro를 바로 볼 수 있습니다. 관절을 마우스로 끌어 움직이고, 충돌체·관성·좌표축을 켤 수 있습니다.
- xacro 파일을 열고 오른쪽 위 미리보기 버튼 또는 `Ctrl+Shift+P` → `URDF Visualizer: Preview URDF/Xacro`.
- `$(find pipe_robot_sim)`은 레포 최상위 `.vscode/settings.json`의 `urdf-visualizer.packages`로 찾습니다. VS Code를 레포 최상위 폴더(`INU-ESE_Capstone_Project`)로 열어야 합니다.

이 문서의 1절부터는 **새 모델이 지켜야 할 규약**입니다. launch, 노드, bench가 이 이름과 토픽을 전제로 동작합니다.

## 1. 폴더와 파일

```
src/pipe_robot_sim/models/<이름>/
  <이름>.urdf.xacro    로봇 모양 (파일 이름 = 폴더 이름)
  robot.yaml           파라미터 (launch, 노드, bench가 같이 읽음)
  layout.yaml          (선택) 부품 배치 — layout_check 용
```

- 실행: `model:=<이름>`. **새 파일을 추가했을 때는** `colcon build --symlink-install`을 한 번 다시 합니다 (설치 폴더에 파일별 링크가 생겨야 함). 이미 있는 파일을 고칠 때는 빌드가 필요 없습니다.
- launch가 xacro에 넘기는 인자: `params_file` (robot.yaml 경로), `pipe_inner_d` (배관 내경 [m]), `suspension` (`all`/`top`, 쓰지 않아도 됨).

## 2. URDF/xacro 규약

| 항목 | 규약 | 쓰는 곳 |
|---|---|---|
| Gazebo 모델 이름 | `pipe_robot` (launch가 정함) | 브리지 토픽, bench |
| 기준 링크 | `base_link` (URDF 루트 = 앞마디 권장) | 정답 위치, RViz, bench |
| 바퀴 구동 | 바퀴 관절마다 `ApplyJointForce` 플러그인 (기본 토픽 `/model/pipe_robot/joint/<관절>/cmd_force`) | `motor_driver` |
| 모터 역기전력 | 바퀴 관절 `damping` = 스톨 토크 ÷ 무부하 속도 | 토크-속도 직선 특성 |
| 관절 상태 | `JointStatePublisher` 플러그인, `<topic>/joint_states</topic>` | 엔코더, RViz, bench |
| 능동 서보 | 관절마다 `JointPositionController`, `<topic>/servo/<관절></topic>` | 서보 명령 |
| 정답 위치 | `OdometryPublisher`, `odom_topic` = `/ground_truth/odom`, `odom_frame` = `world`, `robot_base_frame` = `base_link`, `dimensions` = 3 | odometry 비교, bench |
| IMU | `imu` 센서, `<topic>/imu</topic>` (월드에 Imu 시스템 있음) | odometry |
| ToF | `gpu_lidar` 센서, 토픽 `/tof/front`, `/tof/left`, `/tof/right` (전방은 `/tof/front/points`도 자동 발행) | 브리지 |

- ToF를 쓰면 `robot.yaml`에 `tof: true`를 넣어야 launch가 렌더링 센서 시스템과 센서 전용 배관을 켭니다. 화면(DISPLAY)이 필요합니다 ([06](06_알려진_문제.md) 3번).
- 바퀴는 구(sphere) 충돌체가 배관 메시와 접촉이 안정적이었습니다.

## 3. robot.yaml 규약

ROS 2 파라미터 파일 형식이며, 모든 노드가 같이 읽습니다.

```yaml
/**:
  ros__parameters:
    # 필수
    wheel_joints: [fl_wheel_joint, ...]   # 모터로 돌릴 바퀴 관절 (없으면 모터·엔코더 노드를 안 띄움)
    wheel_radius: 0.012                   # [m]
    encoder_cpr: 2800                     # 출력축 1회전당 카운트
    motor_stall_torque: 0.147             # [N·m]
    motor_no_load_speed: 16.8             # [rad/s]
    body_len: 0.09                        # 앞마디 길이 [m] (spawn_x 없을 때 시작 위치 계산)
    # 선택
    spawn_x: 0.30                         # 시작 x [m] (로봇 전체가 배관 안에 들어가게)
    supply_voltage: 7.4
    rated_voltage: 6.0
    drive_mode: speed_pid                 # speed_pid | open_loop | diff
    kp: 0.01
    ki: 1.0
    kd: 0.0
    servo_joints: [j1_pitch, j1_yaw]      # 서보 관절
    servo_modes: [active, active]         # active 만 브리지 연결
    joint_gap: 0.04                       # 마디 사이 관절부 길이 [m] (layout_check)
    tof: false
    bench_spines: [base_link]             # bench가 배관과 정렬을 재는 링크
```

- 추정값과 실측 방법은 [08 추정값 목록](08_추정값_목록.md).
- `layout_check --apply`가 `seg_len`, `seg_mass`, `seg_com`, `spawn_x`, `body_len`을 자동으로 채웁니다.

## 4. layout.yaml (선택)

```yaml
hull: {outer_d: 56, wall: 2, density: 1.24}          # 몸통 [mm], PLA 밀도 [g/cm³]
wheel_module: {angles: [90, 210, 330], x_half: 14, half_width: 10, r_min: 18}   # 부품 금지 구역 [deg, mm]
segments:                                             # 앞마디부터 순서대로
  front:
    length: 90                                        # [mm]
    link: base_link                                   # 부품 상자를 붙일 URDF 링크
    x_offset: 0.0                                     # 링크 원점 -> 마디 중심 [m]
    parts:
      - {name: esp32, shape: box, size: [21, 17, 8], pos: [30, 0, 0], mass: 5}   # box: [x, y, z] mm
      - {name: cell, shape: cyl_x, size: [14, 50], pos: [-20, 0, 0], mass: 20}   # cyl_x / cyl_z: [지름, 길이]
```

- 부품 옵션: `external: true` (몸통 밖 부품, 몸통 검사 제외), `allow: [다른부품]` (의도적 겹침), `est: true` (추정 치수 표시), `shape: mass` (질량만).
- `layout_check`가 `components.urdf.xacro`를 만들어 줍니다. 모델 xacro에서 include하면 Gazebo와 RViz에 부품 상자가 보입니다.
