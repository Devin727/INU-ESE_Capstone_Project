# 07. 설계 방향과 미결정

이 문서는 **잠정 설계 방향**과 **팀이 정해야 할 것**을 나눠 적습니다. 확정된 것은 없고, 시뮬 결과와 팀 논의에 따라 바뀔 수 있습니다.

## 1. 잠정 설계 방향 (2026-10-15 기준)

| 영역 | 잠정 방향 | 근거 |
|---|---|---|
| 몸체 | 2마디 (앞 100mm, 뒤 110mm), 외경 Ø56, 벽 2mm, PLA 3D 프린트 | 실제 부품 배치 검사 통과 (`two_real/layout.yaml`) |
| 관절 | 2개, 각각 피치+요 2축 능동 서보, 토크 0.35 N·m (MG92B급 가정), 관절부 50mm, 모따기 10mm | 능동 관절이 필수 (수동은 V자로 접힘) |
| 바퀴 | 마디마다 120° 3륜, 크라운 고무 O링 Ø24 | 3륜 120°가 중심 잡기에 유리 (문헌, 시뮬) |
| 바퀴 누름 | 바퀴당 약 11N, 스프링 스트로크 ±20mm | 수직관 등반과 아래 90°의 균형 (시뮬) |
| 구동 | 두 마디 6바퀴 | 앞마디만 구동하면 견인력 부족 (시뮬) |
| 센서 | 전방 VL53L5CX (8×8), 측면 VL6180 ×2, IMU MPU6050, 탐촉자 회전 AS5600 | 센서 제어로 엘보 방향 결정 (시뮬에서 통과) |
| 제어 | follow-the-leader (앞마디가 방향을 정하고 뒷마디가 따라감), 엔코더 기준 | 배관 정보 없이 통과 |
| 칩 | XIAO ESP32S3 Sense (카메라 포함, 앞마디), XIAO ESP32S3 (제어, 뒷마디 UT용) | 구매 리스트 v2의 Pi Zero·ESP32 대체 |
| 배터리 | 14500 ×2 (마디마다 1개, 직렬 2S) | 18650은 바퀴 고리 바닥 틈에 안 들어감 |
| UT | 맞춤 PCB (32×28mm), HV 모듈 HAM1518, 12V 승압, 탐촉자 5P14N (젤 방식, 펌프 없음) | 부품 수와 공간 절충 |
| 탐촉자 기구 | N20 + AS5600 회전, SG90 들기, 펠트 커플런트 | 28BYJ-48 (스텝) 대신 N20 (토크 여유) |
| 롤 | IMU로 기록 (v2 원안). 대책은 미정 | 아래 미결정 4번 |

## 2. 구매 리스트 영향 (잠정)

`two_real` 기준으로 구매 리스트 v2와 달라지는 부품:

| 부품 | v2 | 잠정 | 확인할 것 |
|---|---|---|---|
| 제어보드 | Pi Zero 2 W + ESP32 DevKit | XIAO ESP32S3 Sense ×1 + XIAO ESP32S3 ×1 | 디바이스마트 재고, 카메라 모듈 포함 여부 |
| 배터리 | 18650 ×2 + BMS | 14500 ×2 + 2S 보호회로 | 용량 (주행 시간에 영향) |
| 모터 | N20 1:100 ×3 | N20 1:100 ×6 (두 마디) | 가격 (개당 약 2.2만 원 추정) |
| 관절 서보 | MG90S ×3 | MG92B급 ×4 (앞·뒤 관절 각 2축) | 토크 사양, 크기 |
| 거리센서 | VL53L0X 1, VL6180 2 | VL53L5CX 1, VL6180 2 | 8×8 멀티존 센서 가격과 재고 |
| 탐촉자 회전 | 28BYJ-48 + ULN2003 | N20 + AS5600 | |
| 펌프·탱크 | 연동 펌프 + 10ml 주사기 | 제거 (펠트 방식) | 커플런트 방식을 팀이 승인할지 |

- 링크 원칙: 디바이스마트 우선, 없으면 국내 다른 사이트. 해외 구매는 탐촉자만 허용 (학과 예산 규칙).
- 가격은 예상값이므로 결제 전 확인.

## 3. 팀이 정해야 할 것 (미결정)

### 3-1. 시험 배관의 엘보 종류
- **DV 90° (R61, 국내 판매 주력):** 현실적이지만 급해서 아래로 꺾는 엘보에서 어려움.
- **DV 대곡 90° (R125):** 시뮬에서 훨씬 쉽게 통과. 국내 재고가 드묾.
- 결정이 나야 설계 목표 (급한 엘보까지 갈지)가 정해집니다.

### 3-2. 수직관 (위·아래 90°) 포함 여부
- 포함하면 two_real처럼 바퀴 누름력을 높여야 하고, 아래 90°의 불안정이 문제가 됩니다.
- 수평만이면 tracked도 후보가 됩니다 (정렬이 가장 좋음).

### 3-3. 아래로 90°를 어떻게 할지
- (가) 뒷마디 축소 (110 → 100mm 이하): 부품 배치와 충돌. UT 부품을 더 줄여야 함.
- (나) 내리막 감속 제어: 엘보 직전에 속도를 줄여 고꾸라짐을 막음. 소프트웨어 변경.
- (다) 시험 배관을 대곡으로 바꿔 요구 조건을 낮춤.

### 3-4. 롤(몸통 비틀림)을 구조로 막을지, 기록만 할지
- 구조로 막는다면: 바퀴 배치 변경 (X자 4륜은 배터리 문제), 궤도 전환, 무게중심 낮추기.
- 기록만 한다면: v2 원안대로 IMU로 롤을 기록하고 결함 위치를 시계 방향으로 보정.
- 시뮬에서 같은 토크 차동은 효과가 없었습니다. 차동을 쓰려면 접촉력 기반 분배가 필요할 수 있습니다 (문헌 확인 필요).

### 3-5. 2마디와 3마디 중 무엇으로 갈지
- 2마디: 부품 공간이 빠듯하지만 두 칸 (two_real 배치 통과), 미끄러짐과 위치 오차가 작음.
- 3마디: 공간이 넉넉하고 롤이 작음, 서보 4개와 모터 6개로 부품 수 증가.
- 현재 시뮬 기준 2마디를 잠정 선택.

### 3-6. 탐촉자 기구 크기
- 탐촉자 5P14N의 몸체 외경과 높이가 **미확인** (판매자 문의 필요, 01 문서의 탐촉자 항목 참고).
- 탐촉자 몸체가 크면 뒷마디 배치를 다시 해야 합니다.

### 3-7. 배터리 용량과 주행 시간
- 14500 셀의 용량이 정해지지 않았습니다. 데모 3~5분 주행이면 충분하다는 것이 초기 계획입니다.

### 3-8. 통신 방식
- 교수님 의견: 관 안에서 통신이 된다고 가정. 데모는 Wi-Fi (영상 포함), 현장은 LoRa (요약만) 또는 얇은 테더 (노션 기록).
- 영상은 LoRa로 안 됩니다.

### 3-9. 바퀴 누름력 11N이 실제 기구로 가능한지
- 스프링 상수 1000 N/m, 스트로크 ±20mm, 예압 11mm를 같은 공간에 넣을 수 있는지 CAD로 확인 필요.
