# 07. 설계 방향과 미결정

2026-10-19에 차체 설계를 처음부터 다시 시작했습니다. **정해진 차체 설계는 없습니다.**

## 1. 팀이 정해야 할 것 (차체와 무관하게 남은 질문)

| 질문 | 왜 필요한가 |
|---|---|
| 시험 배관의 90° 엘보: DV 90° (R61, 국내 판매 주력) 또는 DV 대곡 90° (R125, 재고 드묾) | 엘보가 급할수록 마디 길이와 관절 설계가 어려워짐 ([03](03_배관_규격.md)) |
| 수직관 (위·아래 90°) 포함 여부 | 바퀴 누름력, 구동 방식 후보가 달라짐 |
| 탐촉자 5P14N 몸체 외경·높이 | 판매자 확인 전이라 검사 마디 크기를 못 정함 |
| 실물 엘보 치수 (Z, 몸통 내경) 실측 | 시뮬 엘보 R은 상한 추정값 ([08](08_추정값_목록.md)) |
