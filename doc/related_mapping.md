# 배관 위치 추정과 센서 융합 조사

원본 Markdown · **[docs/related_mapping.md](../docs/related_mapping.md)**

배관 로봇의 위치 추정에 사용할 센서와 센서 융합 알고리즘을 조사했다. 아래 방식은 비교 후보이며 프로젝트에 적용할 센서 조합과 알고리즘을 확정하거나 실물 성능을 검증한 결과는 아니다.

## 위치 추정 센서와 접근 후보

| 후보 | 조사 내용과 확인할 사항 |
| --- | --- |
| GPS·IMU | 위치 추정의 출발점으로 검토했다. 실내·배관에서는 GPS 수신이 어려울 가능성이 있어 대체 수단을 조사했다. |
| 인코더·Wi-Fi | 인코더의 이동량과 무선 신호를 함께 사용하는 방안을 검토했다. 실제 결합 방식과 배관 내 정확도는 미정이다. |
| Wi-Fi fingerprinting | 기준 지점의 신호를 미리 수집하고 현재 신호와 비교해 위치를 추정한다. 사전 radio map 수집이 필요하다. |
| Bluetooth AoA·UWB | GPS를 대신할 수 있는 후보로 조사했다. 설치 조건·비용·배관 내 적용성은 구체화하지 않았다. |
| 사전 배관 지도 | 미리 작성한 지도에 현재 위치를 대응시키는 방식을 검토했다. |
| 여러 인코더·카메라 | GPS 대체 또는 보완 방식으로 제시했다. 구체적인 추정 모델과 구현은 후속 과제다. |

Wi-Fi fingerprinting은 기준 지점에서 수집한 무선 신호를 radio map으로 만들고, 로봇의 현재 신호와 비교하는 흐름이다. 원문은 신호 강약을 이용할 것으로 추정했다.

기준 지점마다 ESP32 같은 송신기가 필요할 수 있다는 생각과 비용 우려도 기록했다. 이는 조사 당시의 가설이며, 실제 설치 요구사항이나 비용을 확인한 결론은 아니다. AoA·UWB·Wi-Fi 방식은 사전 환경 준비 부담을 고려해야 한다고 보았지만, 배관 환경에서 비교 시험한 결과는 없다.

## 센서 융합의 공통 흐름

위치·속도·방향 등을 상태 벡터로 두고 **예측 → 관측에 의한 보정**을 반복하는 방식을 조사했다.

| 기호 | 의미 |
| --- | --- |
| `x` | 추정할 상태 벡터 |
| `P` | 상태 오차 공분산 |
| `u` | 제어·이동 입력 |
| `z` | 센서 관측값 |
| `F`, `B`, `H` | 상태 전이, 입력 반영, 관측 모델 |
| `Q`, `R` | 과정 잡음·측정 잡음 공분산 |
| `K` | 관측값을 보정에 반영하는 이득 |

인코더와 IMU를 입력 또는 관측 중 어디에 반영할지는 실제 상태·관측 모델을 정의한 뒤 결정해야 한다.

## 칼만 필터: KF

선형 운동·관측 모델을 사용하는 방식이다. 여러 상태를 함께 추정하는 행렬 형태를 조사했다.

```text
예측
x = F x + B u
P = F P Fᵀ + Q

보정
K = P Hᵀ (H P Hᵀ + R)⁻¹
x = x + K (z − H x)
P = (I − K H) P
```

`F`는 상태가 시간에 따라 변하는 방식이고, `H`는 상태가 센서 측정값으로 나타나는 방식이다. 실제 로봇에 사용할 행렬과 잡음 크기는 정하지 않았다.

## 확장 칼만 필터: EKF

비선형 운동 모델 `xₖ = f(xₖ₋₁, uₖ) + 잡음`과 관측 모델 `zₖ = h(xₖ) + 잡음`을 사용하는 방식이다. 함수의 야코비안으로 공분산을 전파한다.

```text
예측
x = f(x, u)
F = ∂f/∂x
P = F P Fᵀ + Q

보정
H = ∂h/∂x
y = z − h(x)
S = H P Hᵀ + R
K = P Hᵀ S⁻¹
x = x + K y
P = (I − K H) P
```

`F`와 `H`는 각 단계의 해당 상태에서 평가한다. `y`는 실제 관측과 예상 관측의 차이다. 배관 로봇의 `f`, `h`와 야코비안은 아직 구현하지 않았다.

## 무향 칼만 필터: UKF

상태 분포를 대표하는 시그마 포인트를 비선형 모델에 통과시키고, 가중 평균과 공분산을 계산하는 방식이다.

```text
예측
χ = sigma_points(x, P)
χ'ᵢ = f(χᵢ, u)
x = Σ Wᵐᵢ χ'ᵢ
P = Σ Wᶜᵢ (χ'ᵢ − x)(χ'ᵢ − x)ᵀ + Q

보정
𝒵ᵢ = h(χ'ᵢ)
ẑ = Σ Wᵐᵢ 𝒵ᵢ
S = Σ Wᶜᵢ (𝒵ᵢ − ẑ)(𝒵ᵢ − ẑ)ᵀ + R
Pxz = Σ Wᶜᵢ (χ'ᵢ − x)(𝒵ᵢ − ẑ)ᵀ
K = Pxz S⁻¹
x = x + K (z − ẑ)
P = P − K S Kᵀ
```

`Wᵐᵢ`와 `Wᶜᵢ`는 평균·공분산 가중치다. 시그마 포인트 생성 방법과 파라미터는 원문에 정해져 있지 않다.

## 파티클 필터

`N`개의 입자로 여러 위치 가설을 유지한다. 각 입자는 배관 구간·구간 내 위치 같은 상태 `xᵢ`와 가중치 `wᵢ`를 가진다.

1. **초기화:** 시작 위치를 알면 주변에 입자를 배치하고, 모르면 지도 전체에 분산한다.
2. **예측:** 운동 모델에 무작위 잡음을 더해 이동시킨다. 입자가 퍼지는 정도로 불확실성 증가를 표현한다.
3. **관측 보정:** 각 입자에서 예상되는 센서값과 실제 관측값의 적합도로 가중치를 갱신하고 합이 1이 되도록 정규화한다.
4. **재표본화:** 가중치에 비례해 새 입자를 추출하고 가중치를 `1/N`으로 초기화한다.
5. **위치 추정:** 가중 평균, 밀집 입자군 또는 최대 가중치 입자를 대표 위치로 사용한다.

```text
예측
xᵢ = f(xᵢ, u) + 무작위 잡음

관측 보정
wᵢ = wᵢ × p(z | xᵢ)

단일 가우시안 관측 모델 예
p(z | xᵢ) ∝ exp(−(z − h(xᵢ))² / (2R))
```

예측 → 보정 → 재표본화를 반복한다. 여러 위치 가설이 남는 경우에는 단순 평균 대신 밀집한 입자군이나 최대 가중치 가설을 사용하는 방안도 조사했다.

## 후속 설계와 관련 문서

- 실제 센서 조합과 배관 내 수신·측정 조건을 확인한다.
- 상태 벡터, 운동 모델, 관측 모델과 잡음 크기를 정의한다.
- KF·EKF·UKF·파티클 필터 중 적용 방식을 선정하고 시험 데이터로 비교한다.
- 배관 지도 형식과 분기·재방문 시 위치 가설 처리 방식을 정한다.
- 초음파 수집 시점의 위치·자세를 검사 결과와 연결한다.
