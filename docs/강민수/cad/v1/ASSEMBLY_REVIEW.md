# 앞 모듈 조립 검토 — 2026-11-19

이 기록과 `assembly_check_results.txt`는 FIT0522 형상을 반영하기 전의 조립 경로 검사다. 교체 모터 형상으로 확인한 간섭은 [현재 CAD 치수 대조](README.md)에 기록했다.

## 검사 방법과 범위

- Windows, Python 3.11.9, CadQuery 2.8.0 / cadquery-ocp 7.9.3.1.1.
- 실행: `python -B -u assembly_check.py` (이 디렉터리에서 실행, CadQuery 필요).
- 원시 출력: `assembly_check_results.txt`.
- 구매품은 기존 스크립트의 단순 형상 사용. 스프링, 부싱·베어링 실체, 나사·나사 머리, 커넥터·배선, 공구 형상은 제외.
- 내부 뭉치의 앞쪽 삽입: 최종 위치에서 +Z 140 mm 떨어진 곳부터 0 mm까지 2 mm 간격, 71개 위치. 외피만 고정하고 내부 뭉치를 평행 이동.
- 앞 덮개: +Z 40 → 0 mm, 뒤 덮개: −Z 40 → 0 mm, 각각 2 mm 간격 21개 위치. 반대쪽 덮개는 검사 대상에서 제외.
- 유닛 3개를 모두 동일하게 바깥 +2 mm / 기준 0 mm / 안쪽 −3.4 mm에 놓은 세 조건. 유닛별 서로 다른 변위 조합은 검사하지 않음.
- 최종 위치에서는 세 유닛 각각을 ESP32 등 고정 부품 및 덮개와 비교. 유닛 사이 검사는 이번 스크립트 범위 밖.
- 모터: 외피·다른 부품 없이 단일 슬라이더에 뒤쪽에서 삽입, −Z 80 → 0 mm를 2 mm 간격으로 검사.
- 겹침 부피 0.001 mm³ 초과를 보고. Boolean 계산 오류는 무간섭으로 처리하지 않고 실행을 중단.
- 이산 위치 검사이며 위치 사이의 연속 경로, 부품의 탄성 변형, 실제 조립 가능성 전체를 증명하지 않음.

## 형상에서 확인한 조립상 문제

### 1. 바퀴 축 베어링 자리의 위쪽 벽 두께가 0 mm [계산]

> 2026-11-19 이후 수정: 구멍 둘레를 보강해 위쪽 벽 1.5 mm로 바꿈 ([README](README.md) "실물 도착 전 수정"). 아래는 수정 전 기록.

축 중심 y=40.95 mm, 베어링 구멍 반지름 3.55 mm, 지지판 위끝 y=44.5 mm이므로 `44.5 − 40.95 − 3.55 = 0 mm`.

구멍이 위쪽 외곽에 접한다. 구멍 주변을 두께가 있는 벽으로 감싼 구조가 아니므로, 출력물의 베어링 지지·유지에 문제가 생길 수 있다. 지지판 외곽 확대 또는 별도 덮개 같은 보강을 검토할 것. 하중에 대한 파손 여부는 계산하지 않음.

### 2. 베어링·축·기어의 축방향 유지 방식 미정

축 베어링 구멍과 웜 축 베어링 구멍은 관통형이며 빠짐 방지 턱·덮개 형상이 없다. 바깥지름 7 mm라는 가정에 구멍은 7.1 mm이므로 CAD상 지름 차는 +0.1 mm다. 압입 고정으로 단정할 수 없다.

바퀴 축 양끝의 축방향 고정, 웜휠의 축 고정, 웜의 축방향 하중을 받는 구조도 정의해야 한다. 실제 베어링 폭과 기어 부품이 미정이므로 유지 방식의 적합성은 미확인.

### 3. 모터 나사는 바퀴보다 먼저 체결해야 함 [계산에 근거한 조립 순서 제안]

모터 앞면 나사 중 하나의 축선은 (x=10.5, y=26.95) mm이고 바퀴는 x=−11.5…+11.5 mm를 차지한다. 이 축선을 +Z에서 따라가면 현재 단순 바퀴 형상이 가린다. 바퀴 장착 후 직선 드라이버로 접근하는 순서를 전제하면 안 된다.

권장 검토 순서: 모터를 뒤에서 삽입·체결 → 슬리브·웜 구동계 조립 → 미리 허브와 체결한 바퀴를 장착하고 축 삽입. 실제 공구 지름, 나사 머리 및 부품별 삽입 경로 전체는 검증하지 않았으므로 확정 조립 절차는 아님.

### 4. 드라이버 뒤쪽 공간은 0.4 mm [계산]

MDD3A 단순 형상 뒤끝 z=−103.6 mm, 뒤 덮개 바닥 안쪽 z=−104 mm. 사이 거리는 0.4 mm다. 실제 기판 뒷면 납땜·고정 나사 머리 등이 이 단순 형상에 포함되는지 확인이 필요하다. 커넥터와 배선 공간도 별도로 검토해야 한다.

## 남은 검증

- 개별 바퀴·허브·기어·축·베어링·부싱의 삽입 경로와 고정 방식.
- 가이드봉에 스프링·슬라이더를 끼우고 스토퍼를 체결하는 과정.
- 실제 나사 규격·길이·머리와 공구 접근 공간. 플라스틱 탭 또는 인서트의 유지력.
- 커넥터를 연결한 채 외피에 삽입하는 경로, 이동 유닛 배선의 굽힘 여유.
- 출력·실물 조립, 강도, 연속 경로 및 엘보 통과.

권고: 전체 부품을 출력하기 전에 베어링 지지·빠짐 방지와 조립 순서를 정하고, 바퀴 유닛 1개부터 출력·조립 시험할 것. 이 권고는 팀의 확정 결정이 아님.
