# 원통형 배관 검사 로봇 — 바퀴 모듈 설치 공간만 남긴 외피

기존 설계에서 바퀴, 가이드봉, LM4UU 부싱, 스프링, 슬라이더, 모터 형상을 모두 제거하고 **앞/뒤 원통형 외피 각각 120° 간격의 관통 창 3개**만 남겼습니다. 중앙 4링크/5핀 다관절은 외형 배치 참고용입니다.

## 모델 치수 (mm, 임시값)
- 앞 외피 Ø42 × 길이 75, 뒤 외피 Ø42 × 길이 105, 벽 두께 2.5
- 창: 축방향 38 × 둘레 접선방향 24, 각 몸체 3개 (120° 간격)
- 전면 카메라판: Ø42, 중앙 Ø12 구멍 및 LED Ø3.2 구멍 6개 (카메라 규격 미확정)
- 외피/전면판은 개별 STL로 제공. STL에는 다관절이 포함되지 않습니다.

## 중요: 제작 전 확인
- 창 크기는 **바퀴 모듈 조립체의 실제 크기를 반영하지 않은 임시 치수**입니다. 옴니휠 38mm의 전체 이동 궤적과 슬라이더/부싱/모터를 실측해 창의 축방향 길이와 접선방향 폭을 조정해야 합니다.
- 단순 창만 있으므로 모듈 체결홀, 보강 리브, 탈착식 캡 체결, 내부 부품 고정 구조는 아직 없습니다.
- 중앙 관절은 이전 개념도를 유지했을 뿐, 실제 핀 체결/관절 가동이 검증된 출력용 부품이 아닙니다.
- 급격한 90° 숏 엘보 통과와 수직 등판 성능은 검증되지 않았습니다.

## 사용
OpenSCAD 파일 상단 `part`를 `front`, `rear`, `camera_plate`, `joint`, `assembly` 중 하나로 설정하고 F6 렌더 후 STL 내보내기. 별도 STL 파일은 앞/뒤 외피와 카메라판만 제공합니다.
