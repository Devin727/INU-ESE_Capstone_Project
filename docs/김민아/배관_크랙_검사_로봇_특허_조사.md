# 배관 크랙 검사 로봇 관련 특허 조사

특허 출원 가능성을 판단하기 위해 다음 세 영역으로 나눠서 선행 특허를 조사했다.

1. 벽 밀착 구동부
2. UT 탐촉자/회로
3. UT+로봇 결합

---

## 1. 벽 밀착 구동 메커니즘 (슬라이더-크랭크+스프링류)

| 특허/문헌 | 핵심 내용 | 우리 설계와의 관계 |
| --- | --- | --- |
| US9021900B2 / US20130104676A1 (In-pipe inspection robot) | 슬라이더-크랭크 메커니즘으로 관 반경 방향으로 움직이는 다리에 발과 압축스프링으로 된 탄성부를 붙여 관벽에 탄성 압력을 주는 구조 | 거의 동일한 구조가 이미 특허 등록됨 |
| CN107990085A (Multi-pose variable diameter pipeline robot) | 중앙 제어부에 다리를 대칭 배치, 연결대-스프링-서보모터 조합으로 바퀴 위치 조정 | 다리+스프링+서보 조합 특허, 유사 |
| US11209114 (Water pipe inspection robot) | 공압 액추에이터로 3개 부재의 압력을 조절해 관 통과 제어 | 스프링 대신 공압 방식, 같은 목적 |
| MOGRER, MRINSPECT, NTU-Navigator (학술 선행기술) | MOGRER는 가위형 스프링 구조로 관 형상에 따라 자동 회전, NTU-Navigator는 위쪽 바퀴에 스프링을 달아 로봇 높이를 자동 조절 | 특허는 아니지만 심사 시 인용될 수 있는 선행기술 |

**결론**: 슬라이더-크랭크+스프링 방식 자체는 이미 여러 건 특허로 등록되어 있어 신규성 확보가 어려움.

## 2. UT 탐촉자 / 펄서-리시버 회로

| 특허 | 핵심 내용 |
| --- | --- |
| US7104131B2 | 펄서+보호회로+증폭회로를 한 기판에 올려 탐촉자를 케이블 없이 직접 연결 |
| KR20030073551A (휴대용 폴리에틸렌 배관 전기융착부 초음파검사장치) | 제어부, 초음파 펄스발생조절부, 펄스구동부로 구성된 휴대용 UT 검사 장치 |
| KR101186405B1 (초음파 검사방법) | 곡면 형상 파이프 용접부 UT 검사 방법 (기존 방법은 평탄한 면에만 적용 가능했던 한계 지적) |
| KR100817617B1 (구조물의 두께와 물성치 검사장치) | 초음파 센서+분석기로 구성, 군속도 계산으로 두께와 재질 물성치까지 추정 |
| KR101478465B1 (곡배관 용접부 초음파검사방법) | 곡관 용접부 UT 검사 방법 (방사선 검사 대비 시간 단축) |
| KR100966543B1 (유도 초음파 배관 내부 침적층 평가 장치) | 배관 외부 부착 송수신 탐촉부로 원주 방향 유도초음파를 이용해 침적층 두께 평가 |

**결론**: UT 펄서-리시버 회로의 기본 구조(펄서+보호+증폭, ToF 계산)는 국내외에 이미 폭넓게 특허화됨.

## 3. UT + 로봇 결합

| 특허/문헌 | 핵심 내용 |
| --- | --- |
| CN209656625U (해저 배관 굽힘부 피로균열 검출장치) | 환형 고정대에 슬라이딩 블록을 두고 그 위에 UT 탐촉자를 고정, 풀로드를 당기면 탐촉자가 배관 둘레를 따라 이동하며 검사 — 로봇 없이 저비용 구현이 특징 |
| KR100671023B1 (배관 검사 및 청소 로봇) | 이동부+지지부(높낮이 조절 지지바퀴)+브러시부+청소기부+카메라로 구성된 LNG 배관 검사·청소 로봇 — UT 없이 카메라 기반 |
| KR20070027430A (배관 내부 진단용 마이크로 로봇) | 이동로봇 중심축에 분사기를 달아 도료를 분사해 부식 방지 — UT 아닌 도료 분사 기반 |
| IEEE Crack Detection Robot using FPGA (논문) | DC 기어모터 로봇에 초음파 센서를 달아 40kHz 펄스를 쏘고 에코 펄스 폭으로 크랙 유무 판단, FPGA로 처리 |
| PIG 로봇 + UT 결합 연구 (논문) | 영구자석 흡착 방식 크롤러에 UT 비파괴검사 시스템을 결합해 결함 위치 파악 |

**결론**: "로봇+UT" 결합 사례도 이미 다수 존재. 다만 소형(75~100mm) PVC관에 특화된 자체제작 UT 회로 + 저가 소형 로봇 통합 사례는 상대적으로 적음 (기존 특허·논문은 대부분 금속 배관, 대형 배관, 산업용 고가 장비 위주).

## 4. 특허 전략 정리

| 요소 | 신규성 확보 가능성 | 이유 |
| --- | --- | --- |
| 슬라이더-크랭크+스프링 벽 밀착 | 낮음 | US9021900B2 등 이미 등록됨 |
| 펄서+보호+증폭 UT 회로 구조 | 낮음 | US7104131B2, 국내 특허 다수 |
| ESP32 Input Capture 기반 ToF 검출 (ADC 없이) | 중간 | 콘셉트는 흔하지만, 저가 소형 배관로봇에 최적화된 구체적 회로 설계로 청구항을 좁히면 가능성 있음 |
| 75~100mm PVC관 전용 초소형 통합 패키징 | 중간~높음 | 기존 특허 대부분 금속관·대형관 대상, 소형 PVC 특화 사례가 적음 |
| 위 요소들을 하나의 저가 로봇에 통합한 시스템 청구항 | 가능성 있음 | 개별 요소는 공지 기술이어도, 특정 조합·치수·구조의 조합은 결합발명으로 신규성 인정 가능 |

**결론**: 개별 기술 요소(벽 밀착, UT 회로, 로봇+UT 결합) 대부분이 이미 특허·논문으로 공개되어 있어 완전히 새로운 기술로 특허받기는 어려움. 노려볼 지점은:

1. 결합발명으로서 "75~100mm 소형 PVC관 + 저가 ESP32 기반 UT 회로 + 특정 다리 구조"의 구체적 조합
2. 기존 특허에 없는 세부 구현 디테일 (특정 스프링 강성 계산 방식, 특정 압착 기구, 특정 신호처리 알고리즘)
