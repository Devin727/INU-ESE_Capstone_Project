## 2. 교수님 첨언 및 검토 의견

### 2.1. 바퀴 및 주행 구조

- 바퀴 구조가 반드시 **3축일 필요는 없음**.
- 위쪽으로 올라가는 주행은 어려우며, **수직 배관 주행까지 구현하기는 힘들 수 있음**.
- 차체를 지지하는 **기둥 또는 지지 구조를 무엇으로 구성할지** 고민할 필요가 있음.

**검토 아이디어**

1. **보조 바퀴:** 길이를 가변적으로 조절할 수 있게 구성해 차체 중심을 잡는 역할을 부여.
2. **궤도 방식:** 바퀴 대신 또는 바퀴와 함께 궤도형 구동 구조를 검토.
3. **후방 지지 구조:** 차체 맨 뒤에 받침대 또는 꼬리 형태의 구조를 추가해 차체를 위로 들어 올리는 방식 검토.

### 2.2. 검사 방식의 대안

- 초음파 검사가 제대로 구현되지 않는 경우, **카메라로 배관 내부를 실시간으로 보여주는 방식**을 대안으로 고려.
- 촬영한 영상을 사후 분석하여 배관 상태를 확인하는 방법도 검토.
- 따라서 배관 내부에서 자유롭게 움직일 수 있도록 로봇의 **기동력 확보**에 집중할 필요가 있음.

### 2.3. 통신 관련 가정

- 초기 검토에서는 **배관 내부에서 통신이 가능하다고 가정**함.

## 3. 후속 검토 사항

- [ ] 바퀴 장착 방식과 가변 보조 바퀴·궤도 구조 비교
- [ ] 후방 지지대(꼬리) 구조의 실현 가능성 검토
- [ ] 전륜 조향·후륜 구동 방식의 후진 및 굴곡 구간 주행 검토
- [ ] 다중 탐촉자와 단일 회전 탐촉자의 장단점 비교
- [ ] ToF 센서 필요성과 탐촉자 단독 활용 가능 범위 검토
- [ ] 탐촉자 슈·커플런트 공급 및 접촉 방식 검토
- [ ] 시뮬레이션 도구 조사
- [ ] 초음파 검사 구현이 어려울 경우 카메라 기반 검사 방안 검토
- [ ] 배관 내부 통신 가능 여부 실험으로 확인
