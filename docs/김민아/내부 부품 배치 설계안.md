# 배관 검사 로봇 내부 부품 배치 설계

## 1. 설계 개요

### 1.1 설계 목적

PVC 배관 내부를 주행하며 균열을 탐지하는 로봇의 앞·뒤 몸체에 센서, 구동부, 제어부 및 전원부를 효율적으로 배치하기 위한 설계안을 비교한다.

현재 로봇은 **앞 몸체 + 3D 프린팅 다관절 + 뒤 몸체** 구조이며, 내부 공간과 무게중심, 배선, 유지보수 편의성을 고려하여 두 가지 배치안을 검토한다.

### 1.2 기본 설계 조건

| 항목 | 설계 조건 |
| --- | --- |
| 배관 내경 | 100mm |
| 앞 몸체 | 원통형, 외경 42mm × 길이 75mm |
| 뒤 몸체 | 원통형, 외경 42mm × 길이 105mm |
| 몸체 연결부 | 3D 프린팅 다관절 |
| 앞 바퀴 | 38mm 옴니휠 3개 |
| 뒤 바퀴 | 43mm 구동 바퀴 3개 |
| 바퀴 배치 | 몸체 원주 방향 120° 간격 |
| 바퀴 압착 방식 | 가이드봉 + 가이드 부싱 + 압축 스프링 |
| 필수 주행 조건 | 수직 배관 및 짧은 90° 엘보 통과 |

※ 몸체 치수는 현재 모델링 기준이며, 실제 부품 장착 가능 여부에 따라 변경될 수 있다.

### 추가 배치 예정 부품

- 카메라: 배관 내부 영상 확인

- ToF 센서: 벽면 거리 및 배관 형상 변화 감지
- 초음파 송수신 회로: 탐촉자 구동 및 반사 신호 수신
- 전압 조정 및 보호 회로: 배터리 전원 분배

※ 추가 부품의 정확한 모델명과 외형 치수가 모두 확인된 것은 아니므로, 실제 장착 공간은 추후 검증해야 한다.

## 3. 1안 — 전방 검사 집중형

### 3.1 설계 개념

**앞 몸체는 검사 및 관찰 기능, 뒤 몸체는 구동 및 전원 공급 기능에 집중하는 구조**

센서와 검사 장치를 앞 몸체에 집중 배치하고, 모터·제어보드·배터리 등을 뒤 몸체에 배치하여 역할을 구분한다.

### 3.2 앞 몸체 부품 배치

**앞 몸체: 외경 42mm × 길이 75mm**

| 위치 | 배치 부품 | 배치 방법 |
| --- | --- | --- |
| 맨 앞 0~12mm | 카메라 + LED | 전면 원형 장착판에 고정 |
| 앞쪽 12~25mm | 전방 ToF 센서 | 카메라 시야를 가리지 않는 위치 |
| 중간 25~60mm | 옴니휠 3개 및 압착 모듈 | 원주 방향 120° 간격 |
| 중간 측면 | 초음파 탐촉자 | 바퀴와 간섭하지 않는 측면 접촉 모듈 |
| 뒤쪽 60~75mm | 케이블 및 다관절 연결부 | 중앙 배선 통로 확보 |

**초음파 탐촉자 배치 시 고려 사항**

- 탐촉자는 배관 내벽에 직접 접촉해야 한다.
- 바퀴 압착 모듈과 간섭하지 않도록 배치해야 한다.
- 탐촉자용 별도 압착 구조를 고려해야 한다.
- 안정적인 초음파 측정을 위한 커플런트 공급 또는 도포 방식이 필요하다.

### 3.3 뒤 몸체 부품 배치

**뒤 몸체: 외경 42mm × 길이 105mm**

| 위치 | 배치 부품 | 배치 방법 |
| --- | --- | --- |
| 앞쪽 0~20mm | 다관절 체결부 및 배선 커넥터 | 관절 운동 공간 확보 |
| 중간 20~70mm | 모터 3개 + 바퀴 압착 모듈 | 원주 방향 120° 배치 |
| 남는 내부 공간 | ESP32, MDD3A 2개 | 적층 또는 측면 장착 |
| 뒤쪽 | 7.4V 배터리 및 전원 회로 | 탈착 가능한 고정 트레이 |

※ 위 위치는 초기 배치 구상이며, 실제 부품 치수와 간섭 검토를 거쳐 조정해야 한다.

### 3.4 장점

1. **기능별 역할 구분이 명확함**: 앞 몸체는 검사, 뒤 몸체는 구동을 담당하여 구조를 이해하고 관리하기 쉽다.
2. **센서 통합 및 검사 위치 관리가 용이함**: 카메라와 초음파 탐촉자가 같은 몸체에 배치되어 검사 기능을 집중적으로 설계할 수 있다.
3. **초기 제작 및 조립이 상대적으로 간단함**: 기능별로 모듈을 구분하여 제작 및 테스트하기 편리하다.
4. **유지보수 시 기능별 접근이 용이함**: 센서 관련 문제와 구동 관련 문제를 구분하여 점검하기 쉽다.

### 3.5 단점

1. **뒤 몸체에 무게가 집중될 가능성**: 모터, 배터리, 제어보드가 집중되어 무게중심이 뒤쪽으로 이동할 수 있다.
2. **뒤 몸체 내부 공간 부족**: 모터 드라이버와 배터리, ESP32가 서로 간섭할 가능성이 있다.
3. **센서 배선 길이 증가**: 앞쪽 센서에서 뒤쪽 제어부까지 다관절을 통과하는 배선이 필요하다.
4. **구동부 발열 및 배선 집중**: 모터와 제어 회로가 밀집되어 열 관리와 배선 정리가 어려울 수 있다.

## 4. 2안 — 기능·무게 분산형

### 4.1 설계 개념

**앞 몸체에는 센서와 센서 제어부를, 뒤 몸체에는 구동부와 주행 제어부를 배치하는 구조**

ESP32 2개를 앞뒤에 각각 배치하여 센서 제어와 모터 제어를 분리하고, 뒤 몸체의 내부 공간 부담을 줄이는 방식이다.

### 4.2 앞 몸체 부품 배치

| 부품 | 배치 위치 및 방법 |
| --- | --- |
| 카메라 + LED | 몸체 가장 앞쪽 |
| 전방 ToF 센서 | 카메라 옆 |
| 5MHz 초음파 탐촉자 | 바퀴 사이 측면 |
| 옴니휠 3개 | 몸체 원주 방향 120° 간격 |
| ESP32 1개 | 바퀴 모듈을 피한 내부 공간 |

**앞쪽 ESP32 담당 기능**

- ToF 센서 데이터 수집
- 초음파 탐촉자 트리거 제어
- 센서 데이터 처리 및 전달
- 앞쪽 검사 장치 제어

### 4.3 뒤 몸체 부품 배치

| 부품 | 배치 위치 및 방법 |
| --- | --- |
| FIT0522 모터 3개 | 바퀴 이동 브래킷에 각각 고정 |
| 43mm 고무바퀴 3개 | 몸체 원주 방향 120° 간격 |
| ESP32 1개 | 모터 및 엔코더 제어 |
| MDD3A 2개 | 모터 배선 가까이 |
| 7.4V 560mAh 배터리 | 가능한 한 몸체 중심축 가까이 |
| 전압 조정·보호 회로 | 배터리와 제어부 사이 |

**뒤쪽 ESP32 담당 기능**

- 모터 3개 구동 제어
- 엔코더 데이터 수집
- 주행 속도 및 방향 제어
- 앞쪽 ESP32와 통신

### 4.4 앞뒤 몸체 간 연결

앞뒤 ESP32가 서로 통신할 수 있도록 다관절 내부에 통신선과 필요한 전원선을 배치한다.

- 다관절의 굽힘을 방해하지 않는 배선 경로 확보
- 관절 회전 시 케이블이 당겨지지 않도록 여유 길이 확보
- 반복 굽힘에 따른 케이블 손상 방지
- 전원선 및 통신선의 간섭 최소화

### 4.5 장점

1. **무게 분산 가능**: ESP32를 앞뒤에 분산 배치하여 뒤 몸체의 부품 집중을 완화할 수 있다.
2. **제어 기능 분리**: 센서 제어와 모터 제어를 각각 독립적으로 구성할 수 있다.
3. **뒤 몸체 내부 공간 확보**: 일부 제어 기능을 앞쪽으로 이동시켜 뒤쪽 배치 부담을 줄일 수 있다.
4. **기능 확장에 유리**: 향후 센서 추가 및 제어 알고리즘 변경 시 기능별로 개발할 수 있다.

### 4.6 단점

1. **앞 몸체의 무게 증가**: 센서 외에 ESP32가 추가되어 앞쪽 하중이 증가한다.
2. **배선 구조 복잡**: 앞뒤 제어보드 간 통신 및 전원 배선이 필요하다.
3. **제어 프로그램 복잡도 증가**: 두 ESP32 간 데이터 송수신과 동기화 기능을 구현해야 한다.
4. **조립 및 유지보수 난이도 증가**: 앞뒤 전자부품을 각각 관리해야 하며 통신 문제도 점검해야 한다.

## 6. 설계 시 추가 검토 사항

### 6.1 모터 및 바퀴 모듈 간섭

- 뒤 몸체 내부에 FIT0522 모터 3개가 배치 가능한지 확인
- 바퀴 이동 브래킷의 압착 및 복원 범위 확인
- 모터와 가이드봉, 스프링 사이의 간섭 확인
- 120° 간격으로 배치한 모듈 사이의 충돌 여부 검토

### 6.2 초음파 탐촉자 배치

- PVC 배관 내벽과의 접촉 유지
- 탐촉자 압착력 확보
- 바퀴 모듈과의 간섭 방지
- 커플런트 공급 및 유지 방식 검토

### 6.3 내부 전자부품 배치

- ESP32 및 MDD3A 실제 외형 치수 확인
- 배터리 고정 및 탈착 공간 확보
- 초음파 송수신 회로 탑재 공간 확인
- 전원 및 통신 배선 경로 설계

### 6.4 전원 및 구동 안정성

- 7.4V 배터리와 6V 모터 간 전압 적합성 확인
- 모터 드라이버 허용 전압 및 전류 검토
- 모터 출력축과 고무바퀴 결합 가능 여부 확인
- 수직 주행에 필요한 모터 토크 및 바퀴 마찰력 검증

### 6.5 배관 통과 가능성

- 내경 100mm 배관에서 바퀴 압착 상태 확인
- 짧은 90° 엘보 구간에서 몸체 간섭 검토
- 다관절 최대 굽힘각 확인
- 수직 주행 시 하중 전달 및 미끄러짐 여부 확인

## 7. 최종 검토 방향

### 1차 검토안: 전방 검사 집중형

초기 모델링 및 조립 과정에서는 **1안인 전방 검사 집중형을 우선 검토**한다.

**선정 이유**

- 앞뒤 몸체의 기능을 명확하게 구분할 수 있음
- 초기 부품 배치와 조립 구조를 비교적 단순하게 설계할 수 있음
- 센서부와 구동부를 나누어 개별적으로 테스트하기 편리함
- 초기 주행 성능 및 기구 간섭 검증에 집중할 수 있음

다만 뒤 몸체에 모터, 드라이버, 배터리 등이 집중되므로 실제 장착 공간 확보가 핵심 검토 사항이다.

### 2차 검토안: 기능·무게 분산형

1안의 내부 공간이 부족하거나 센서 기능을 확장할 필요가 있을 경우, **2안인 기능·무게 분산형을 대안으로 검토**한다.

**검토 이유**

- 뒤 몸체의 전자부품 집중 완화
- 앞뒤 ESP32를 활용한 기능별 제어
- 센서 기능 확장 및 모듈별 유지보수 가능성

### 향후 모델링 순서

1. 앞쪽 옴니휠 압착 모듈 1개 설계
2. 가이드봉, 가이드 부싱, 이동 브래킷 및 스프링 배치
3. 앞 몸체에 옴니휠 모듈 3개를 120° 간격으로 배치
4. 뒤쪽 모터 구동 모듈 1개 설계
5. 뒤 몸체에 구동 모듈 3개를 배치하고 간섭 검토
