## UT 센서 & 구동부 구현 기술 조사서

## 1. UT(Ultrasonic Testing)란

관 벽에 초음파 펄스를 쏘고 반사파(에코)가 돌아오는 시간을 측정해 벽 두께·내부 결함을 찾는 비파괴검사 기법.

- 정상 벽: 후벽에서 반사되어 일정한 시간에 에코 돌아옴
- 크랙 존재: 크랙 표면에서 먼저 반사 → **후벽 에코보다 빠른 신호**로 감지
- 거리 = (음속 × 시간) / 2 (왕복이므로 2로 나눔)

## 2. 팀 역할 분배

| 역할 | 담당 업무 | 필요 배경 |
| --- | --- | --- |

| 임베디드/펌웨어 (1명) | ESP32 펄스 생성, Input Capture 타이머, 통신 | MCU, 타이머 인터럽트 |
| 기구 설계 (1~2명) | 구동부, 슬라이더-크랭크, 탐촉자 압착 짐벌 | CAD, 3D 프린팅 |
| 제어/SW (1명) | 주행 제어, 위치 추적, 데이터 시각화 | 모터 제어, 알고리즘 |

## 3. UT 회로 구현

### 3-1. 제작 순서

1. 만능기판(프로토보드)에서 시작 — 브레드보드는 고전압·MHz 신호에서 노이즈 심해 사용 금지
2. HV 30~50V부터 시작해서 스코프로 펄스 파형 확인
3. PVC 정상부에 탐촉자 대고 후벽 에코 확인 (두께 ÷ 2258m/s 계산값과 비교)
4. 인공 균열 시편(깊이별)에서 후벽보다 먼저 오는 에코 확인
5. 노이즈 레벨 파악 후 비교기 임계값 결정 → 최종 PCB 설계에 반영

### 3-2. 구매 리스트

| 항목 | 예시 제품 | 예상 가격 | 구매처 |
| --- | --- | --- | --- |
| 탐촉자 | 1~2.25MHz 수직 접촉식 UT 탐촉자 | 5~10만원 | 알리익스프레스, 타오바오 |
| 게이트 드라이버 | TC4420 / TC4429 | 1,000~2,000원 | 디바이스마트 |
| HV MOSFET | IRF840(500V), STF13NM60N | 1,000원대 | 디바이스마트, LCSC |
| DC-DC 승압모듈 | 가변 12V→0-200V 부스트 모듈 | 1~2만원 | 알리익스프레스 |
| HV 캐패시터 | 세라믹/필름, 1~4.7nF/250V 이상 | 개당 500원 | LCSC, 디바이스마트 |
| 다이오드 (보호회로) | 1N4148, BAV99 | 매우 저가 | 어디서나 |
| 프리앰프 | OPA657, AD8021급 고속 op-amp | 5,000~1만원 | 디지키/마우저 직구 |
| 비교기 | LM311(테스트용) | 500원 | 디바이스마트 |
| MCU | ESP32 DevKit | 5,000~1만원 | 국내 어디서나 |
| 프로토보드 | 양면 동박 만능기판 | 2,000원 | - |

* 프리앰프·탐촉자는 국내 재고가 적어 디지키/마우저 직구나 알리익스프레스 필요

### 3-3. 최종 PCB (로봇 탑재용)

- 오실로스코프 없이 **비교기 출력 → ESP32 Input Capture 타이머**로 ToF 측정 (고속 ADC 불필요)
- ESP32 타이머 80MHz 기준 분해능 약 12.5ns → PVC 두께 분해능 약 0.014mm
- KiCad로 설계 → JLCPCB/PCBWay로 소량 제작 주문
- HV부와 로직부는 기판에서 물리적으로 분리, 그라운드 플레인 확실히

### 3-4. 자주 막히는 지점

- **주파수**: 5MHz만 시도하다 반사파 안 보이면 PVC 감쇠 때문일 가능성 높음 → 1~2.25MHz도 병행 시도
- **노이즈**: HV 펄스가 ESP32에 노이즈 유발 → 그라운드 분리, 디커플링 캐패시터, 필요시 옵토커플러로 트리거 신호 절연
- **디버깅**: 펄서/수신부/탐촉자 중 원인 특정 어려움 → MOSFET 드레인 → 탐촉자 입력 → 프리앰프 출력 → 비교기 출력 순서로 스코프 확인

### 3-5. 회로 설계 주의점

- 펄스 폭: 탐촉자 주파수의 반주기 (2.25MHz≈220ns, 5MHz≈100ns)
- 탐촉자~기판 케이블 최대한 짧게 (임피던스 부정합 방지)
- 커플런트(젤/물) 필수 — 공기층 있으면 초음파 전달 안 됨. 탄성 패드는 대안이나 PVC 감쇠 확인 필요

## 배관 주행 로봇 — 구체적 구현 가이드

75~100mm PVC관 안에서 움직이는 로봇은 크게 

① 벽 밀착 기구, ② 구동부, ③ 탐촉자 압착 기구, ④ 전자/제어로 나뉜다.

---

## 1. 전체 구조 컨셉

| 방식 | 특징 | 75~100mm 스케일 적합도 |
| --- | --- | --- |
| 바퀴형 (3~4개 다리, 스프링 밀착) | 다리마다 바퀴 달고 스프링으로 벽에 밀착, 관경 변화에 자동 대응 | ✅ 적합 |
| 체인/트랙형 | 무한궤도로 접촉면 넓힘, 마찰력은 좋지만 관경 변화 대응 어려움 | 관경이 거의 고정이면 고려 가능 |

**추천**: 슬라이더-크랭크 + 스프링 방식의 3~4다리 바퀴형. 관경 변화(75↔100mm)에 자동 대응되고 3D프린팅으로 제작 가능.

---

## 2. 벽 밀착 기구 — 슬라이더-크랭크 + 스프링

### 원리

- 로봇 중심축에서 뻗어나온 크랭크(다리) 끝에 바퀴 부착
- 크랭크는 슬라이더(직선 운동 부품)와 링크로 연결
- 슬라이더와 몸체 사이 스프링 → 관경 좁아지면 스프링이 밀어서 바퀴가 벽에 붙고, 관경 넓어지면 스프링 늘어나며 크랭크 벌어짐

### 설계 포인트

- 다리 개수: 3개(120도 배치) 또는 4개(90도 배치) — 3개가 안정적이고 부품 수 적어 시작하기 좋음
- 스프링 강성: 위쪽 바퀴 기준으로 설계 (위쪽이 중력 때문에 접촉력 약해서 먼저 떨어짐)
- 스프링 종류: 인장/압축 스프링, 규격은 실험적으로 결정 (McMaster-Carr, 국내 스프링 전문점, 또는 알리에서 다양한 강성 세트 구매)

### 구매/제작 리스트

| 항목 | 예시 | 비고 |
| --- | --- | --- |
| 프레임/다리/바퀴 | 3D프린팅 (PLA 또는 PETG) | 설계는 Fusion360 무료 학생 라이선스 |
| 스프링 | 인장/압축 스프링 세트 (다양한 강성) | 알리익스프레스 "extension spring assortment kit" |
| 힌지/핀 | M3 볼트+너트 또는 스틸 핀 | 다이소/철물점도 가능 |
| 베어링 (선택) | 미니 볼베어링 (바퀴 회전축) | 마찰 줄이려면 권장, 없어도 부싱으로 시작 가능 |

## 3. 구동부 — 모터와 바퀴

| 항목 | 추천 | 비고 |
| --- | --- | --- |
| 모터 | N20 기어드 DC모터 또는 서보모터 | N20이 소형 로봇에 흔히 쓰임 |
| 모터 드라이버 | TB6612FNG 또는 L298N | 소형이면 TB6612 추천, ESP32 PWM으로 제어 |
| 바퀴 | 3D프린팅 + 고무 O링 | O링으로 접지력 크게 개선 |
| 엔코더 (선택) | 모터 축에 홀센서 or 광학 엔코더 부착 | 이동 거리 = UT 측정 위치 매칭에 필수 |

**모터 개수**: 다리 1개만 구동해도 관 형상 따라 자동 회전하는 방식(MOGRER 방식)도 있으나, 제어 단순성과 견인력 안정성을 위해 **각 다리마다 모터 1개씩 구동** 권장.

---

## 4. 탐촉자 압착 기구

- 로봇 몸체 중앙(또는 다리 중 하나)에 서보모터 + 짐벌 구조로 탐촉자를 관벽에 압착
- 짐벌은 유니버설 조인트나 2축 힌지로 3D프린팅 — 탐촉자가 관 곡면에 맞춰 자유롭게 기울어지도록
- 커플런트(젤)는 탐촉자 주변 소형 스펀지/펠트로 마모 시에도 유지되게 하는 방식 고려 가능

## 6. 제작 순서 (추천)

1. 바퀴+다리 1세트만 먼저 프린팅 → 스프링 강성 테스트 (75mm, 100mm 모의관에서 접촉력 확인)
2. 다리 3개 조립 + 모터 연결 → 실제 PVC 관에서 주행 테스트 (전진/후진)
3. 탐촉자 압착 기구 추가 → 주행 중 탐촉자가 벽에 계속 붙어있는지 확인
4. UT 회로 탑재 + 엔코더로 위치 추적 통합
5. 엘보/T자 구간 통과 테스트 (독립 스프링 방식의 필요성 확인)

## 2. 전체 시스템 구조 (보드 역할 분담)

| 보드 | 담당 |
| --- | --- |
| ESP32-S3 | 엔코더 계수, 바퀴 PID, 모터 PWM, 조향 서보, 탐촉자 접촉 서보, 즉시정지 |
| Raspberry Pi (초기엔 노트북 대체) | 분기 인식, 지도 갱신, 탐색 알고리즘, 파형 분석·결함분류·저장 |

### 조립 순서

1. ESP32-S3와 Raspberry Pi를 로봇 몸체 중앙 격실(3D프린팅 케이스)에 나란히 고정 — 진동 방지를 위해 양면테이프+나사 고정 병행
2. ESP32-S3 ↔ Raspberry Pi 연결: USB-UART 또는 이더넷(테더) 케이블로 연결. 배관 내부 Wi-Fi는 불안정하므로 초기엔 무조건 유선
3. 전원 배선을 먼저 끝내고 신호 배선은 나중에 (전원 쇼트 시 신호선까지 타지 않도록)
4. 부팅 순서 확립: 로직 전원(3.3V/5V) 먼저 인가 → 모터 전원 나중 인가 — 순서 반대로 하면 초기 서지로 MCU가 리셋될 수 있음

## 3. 주행부

| 방식 | 추천도 |
| --- | --- |
| 일반 바퀴형/차동구동 | 1차 시험 우선 |
| 바퀴-다리형 | 바퀴형 걸릴 때 대안 |
| 벽 밀착형(슬라이더-크랭크+스프링) | 중심정렬 중요할 때 |

### 조립 순서

1. 섀시 프린팅: 3D프린터로 다리 3개(120도 배치) + 중앙 허브 프린트, PLA보다 PETG 권장(내구성)
2. 모터 장착: N20 기어드모터를 각 다리 끝단에 볼트(M2~M3)로 고정. 감속기어 출력축 방향이 바퀴 회전축과 일치하는지 먼저 확인
3. 바퀴 장착: 모터 축에 바퀴를 압입 또는 세트스크류로 고정 → 고무 O링을 바퀴 홈에 끼워 접지력 확보
4. 엔코더 부착: 모터 축(또는 별도 아이들축)에 엔코더 디스크 장착, 슬릿/홀센서가 디스크와 0.5~1mm 간격 유지하도록 정렬 — 너무 붙으면 마찰, 너무 떨어지면 오검출
5. 슬라이더-크랭크 링크 조립: 다리와 슬라이더를 핀(M3 볼트+너트)으로 힌지 연결, 스프링을 슬라이더-몸체 사이에 인장 상태로 걸기
6. 압착력 테스트: 75mm, 100mm 모의관에 넣어서 위쪽 다리가 벽에서 뜨지 않는지 확인 (안 뜨면 다음 단계, 뜨면 스프링 강성 재조정)
7. 배선: 모터 리드선(2가닥)을 모터드라이버(TB6612FNG) 출력단에 납땜/커넥터 연결 → 드라이버 입력단은 ESP32-S3의 PWM핀+방향제어핀(2개)에 연결
8. IMU 장착: 로봇 무게중심에 최대한 가깝게(보통 중앙 허브) 고정, I2C(SDA/SCL 2선)로 ESP32-S3에 연결
9. 개별 테스트: 로봇을 손으로 든 상태에서 모터 회전방향, 엔코더 카운트 증감, IMU 값 변화를 먼저 확인 후 실제 관 주행 테스트로 넘어가기

## 4. 매핑부

| 센서 | 역할 |
| --- | --- |
| 전방 Multi-Zone ToF (VL53L8CX급) | 직선/엘보/T분기 구조 판단 |
| 측면 ToF ×4 | 관경, 로봇 중심위치 |
| 엔코더+IMU | 이동거리, 자세 |
| 분기점 카메라 | 노드 재인식 보조 |

### 조립 순서

1. 전방 ToF 장착: 로봇 정면 중앙, 진행방향과 정확히 수직으로 고정 (기울면 거리값 왜곡) — 브라켓은 3D프린팅으로 제작해 각도 고정
2. 측면 ToF ×4 장착: 90도 간격(상/하/좌/우)으로 측면 브라켓에 고정, 각 센서가 관벽을 향하도록
3. I2C 배선: ToF 센서들은 기본적으로 같은 I2C 주소를 쓰는 경우가 많으므로 TCA9548A 같은 I2C 멀티플렉서를 하나 두고, 각 채널에 센서 하나씩 연결 (또는 센서별 XSHUT핀으로 순차 부팅 후 주소 재할당)
4. 배선 정리: 5개 ToF의 SDA/SCL 공통선을 멀티플렉서로 모아 ESP32-S3의 I2C핀 하나로 정리
5. 분기점 카메라 연결: Raspberry Pi CSI 커넥터에 카메라 리본케이블 연결, 케이블은 진동 대비 여유길이로 배선하고 케이블타이로 고정
6. 소프트웨어 확인: ESP32에서 5개 ToF 값을 일정 주기로 읽어 타임스탬프와 함께 Pi로 전송 → Pi에서 값 수신이 끊기지 않는지 먼저 확인 (I2C는 배선이 길면 노이즈에 약함, 필요시 풀업저항 값 조정)

## 5. UT(초음파 검사)부

| 블록 | 부품 |
| --- | --- |
| 트리거 | ESP32 |
| 게이트드라이버 | TC4427/MIC4420급 |
| HV스위치 | 200V이상 N-MOSFET |
| 고전압전원 | DC-DC 승압모듈(0~200V가변) |
| 펄스형성 | HV캐패시터+충전저항+댐핑저항 |
| T/R보호 | 1N4148/BAV99 |
| 프리앰프 | 고속op-amp(OPA657급) |
| 비교기 | LM311→최종 고속비교기 |
| 탐촉자 | 1~2.25MHz 직접접촉식 |

### 조립 순서 (회로 제작 단계)

1. 기판 레이아웃 먼저 설계: 만능기판을 HV부(펄서+캐패시터+MOSFET)와 로직부(ESP32+비교기)로 물리적으로 좌우 분리, 가운데 그라운드 슬릿 확보
2. 부품 실장 순서: 저항·다이오드 등 수동소자 먼저 → IC 소켓 → 캐패시터 → 마지막에 HV 캐패시터/MOSFET (고전압 부품은 맨 나중에 장착해서 조립 중 실수로 감전되는 일 방지)
3. 배선 순서: 트리거(ESP32) → 게이트드라이버 → MOSFET → HV캐패시터 순으로 한 블록씩 완성하고 그때마다 스코프로 확인 후 다음 블록 진행
4. 탐촉자 커넥터 연결: SMA/BNC 커넥터를 기판에 직접 납땜, 탐촉자 케이블은 최단 길이로 (임피던스 부정합 방지)
5. 그라운드 처리: HV부와 로직부 그라운드는 한 점(스타 그라운드)에서만 연결 — 여러 점에서 연결하면 그라운드 루프로 노이즈 유입

### 조립 순서 (로봇 탑재용 압착 기구)

1. 서보 마운트 제작: 서보모터를 로봇 하단부(또는 별도 다리)에 3D프린팅 브라켓으로 고정
2. 짐벌 조립: 서보 축에 링크암을 연결하고, 링크암 끝에 2축 힌지(유니버설 조인트류)로 탐촉자 홀더 장착 — 탐촉자가 앞뒤/좌우로 자유롭게 기울어지는지 손으로 먼저 확인
3. 탐촉자 장착: 홀더에 탐촉자를 끼우고 케이블은 UT 기판까지 최단거리로 배선, 케이블에 여유(서비스루프) 약간 남겨서 서보 움직임에 걸리지 않게
4. 커플런트 저장 구조 (선택): 탐촉자 주변에 작은 스펀지/펠트 링을 둘러 젤이 마르지 않게 보완
5. 로봇 몸체에 최종 고정: 압착기구 전체를 로봇 하단에 볼트로 고정, 서보 신호선을 ESP32-S3 GPIO(서보 전용 PWM핀)에 연결
6. 전원 배선: HV부는 별도 배터리 또는 별도 레귤레이터 라인 사용, 로직부(3.3V/5V)와 물리적으로 분리 배선
7. 동작 테스트: 로봇을 모의관에 넣고 정지 → 서보 압착 → 탐촉자가 관벽에 실제로 닿는지 육안 확인 → 펄스 발생 후 스코프로 에코 확인

## 6. 카메라부

### 조립 순서

1. 카메라 모듈을 로봇 전면 상단, LED링과 동심원이 되도록 고정 (LED링 안쪽 구멍에 렌즈가 오도록)
2. LED링은 별도 레귤레이터로 전원 공급해 밝기 조절 가능하게 배선 (밝기가 카메라 전원과 공유되면 전압강하로 화면이 흔들릴 수 있음)
3. Raspberry Pi CSI 리본케이블 연결, 진동으로 커넥터가 빠지지 않도록 케이블타이로 고정
4. 카메라 프레임에 로봇 위치(엔코더+IMU 기반 추정치)를 타임스탬프로 태깅해 저장하는 소프트웨어 연동 확인
