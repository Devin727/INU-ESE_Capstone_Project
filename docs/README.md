# 프로젝트 문서

이 디렉토리는 프로젝트의 실험계획서, 회의록, 참조문서 등을 정리하고 공유하는 공간입니다.

## 이전 저장소에서 이관한 개발 기록

기존 저장소 `alaekakan/INU-ESE_Capstone_Project`에 게시했던 조사·설계 문서와 CO₂ 추진 시뮬레이션 시험 기록은 [개발 기록 목록](../doc/README.md)에 정리되어 있습니다.

- [CO₂ 추진 배관 로봇 시험 및 기록 검증](../doc/2026-10-29-co2-pipe-robot-gazebo-tests.md): 3 N 연속 추진, 20 g 간격 질량 시험과 원시 기록.
- 이 시험은 Gazebo Sim 10.5.0 기반의 별도 과거 실험이며, 현재 `simulation/`의 Ubuntu 22.04·ROS 2 Humble·Gazebo Fortress 모델에 통합하거나 해당 환경에서 재검증한 결과는 아닙니다.
