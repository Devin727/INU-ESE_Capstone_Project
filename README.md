# INU-ESE_Capstone_Project
2026 Fall – 2027 Spring Capstone Design Project (Team: 황제펭귄살리기프로젝트)

## 프로젝트 설명

내경 약 100 mm의 PVC 배관 내부를 주행하며 배관 구조를 매핑하고, 카메라와 초음파로 내부 이상과 균열을 검사하는 로봇 시스템을 개발합니다.

## 디렉토리 구성

- [docs/](docs/README.md): 공통 문서와 개인별 조사 자료
- [drive/](drive/README.md): ESP 기반 주행부
- [ultrasonic/](ultrasonic/README.md): 초음파 회로와 실험
- [mapping/](mapping/README.md): ToF + 엔코더 기반 매핑
- [vision/](vision/README.md): 카메라를 이용한 파이프 내부 확인
- [mechanical/](mechanical/README.md): 3D 프린팅 부품과 차체 조립
- [simulation/](simulation/README.md): 시뮬레이션
- [drive/ESP_Code/](drive/ESP_Code/README.md): ESP 모터·엔코더 제어 코드
